01 / Framework

The three failure modes

A name dies for one of three reasons. The first is the one most people miss; the last is the one they trust by mistake.

01

Adjacent-domain collision is the worst

It kills a name even when the literal string is free. If a live product in your own vertical already uses the word, the namespace is poisoned regardless of registry availability.

02

Descriptive / generic = domain-free but weak

Plain labels are usually available precisely because nobody can own them. That same plainness makes them weak to trademark challenge and impossible to win on SEO.

03

Search visibility ≠ availability

A quiet search result does not mean the name is free. Always verify against WHOIS, the registry, and trademark databases before trusting it.

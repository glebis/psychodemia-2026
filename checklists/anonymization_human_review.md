# Чек-лист: ручная проверка анонимизации (после автоматики)

Автоматика убирает ~90% стандартных ПД. Оставшиеся 10% — самые опасные. Прочитайте текст
глазами человека, который хочет найти вашего клиента.

## Стандартные ПД
- [ ] Имена (клиент, семья, друзья, коллеги)
- [ ] Даты (рождения, события, сессии)
- [ ] Адреса, районы, географические указания
- [ ] Телефоны, email, соцсети, мессенджеры
- [ ] Номера документов, полисов

## Терапевтические ПД
- [ ] Названия клиник, учреждений
- [ ] Имена врачей, препараты + дозировки
- [ ] Уникальные жизненные события с деталями
- [ ] Судебные/правовые детали

## Квази-идентификаторы (то, что не ловит модель)
- [ ] Редкая профессия + город (напр. «единственный рыжий программист в Костроме»)
- [ ] Уникальная семейная конфигурация
- [ ] Публичные события с участием клиента
- [ ] Характерные хобби/привычки, специфический диалект

> Если хотя бы одна комбинация делает человека узнаваемым — переформулируйте, сохранив
> клинический смысл. Только вы можете это оценить.

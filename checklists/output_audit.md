# Чек-лист: аудит вывода AI (анти-галлюцинация)

Прогоняйте по каждому отчёту модели перед тем, как доверять ему.

- [ ] Под каждым утверждением есть **прямая цитата**?
- [ ] Помечен статус: **подтверждено / разумный вывод / не подтверждено**?
- [ ] Все «не подтверждённые» — удалены или понижены?
- [ ] Уверенность словами (высокая/средняя/низкая), а **не в процентах**?
- [ ] Указаны **альтернативные** объяснения?
- [ ] Где мало контекста (пропущенные сессии, культурный фон) — уверенность понижена?
- [ ] Нет диагнозов, оценки суицидального риска, решений о лечении?
- [ ] Выводы сформулированы как **гипотезы для супервизии**, не как факты?

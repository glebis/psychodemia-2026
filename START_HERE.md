# START HERE

Это материалы мастер-класса «Паттерны в массиве сессий». Всё работает на **синтетических**
данных — это инструментальная демонстрация, не клиническая валидация.

## За 3 минуты

1. Поставьте Claude Code: `npm install -g @anthropic-ai/claude-code` (или `brew install claude-code`).
2. В этой папке: `make demo` — увидите меню из трёх клинических вопросов.
3. Откройте `prompts/PROMPTS.md` — копируйте промпты в Claude Code по одному.
4. Если живой запуск тормозит — откройте готовый ответ из `reference-outputs/`.

## Главное правило приватности

**Локальные инструменты ≠ локальный инференс.** Claude Code читает файлы локально, но по
умолчанию рассуждает в облаке (API Anthropic). Два честных пути:
- **Локально:** Claude Code → Ollama/LM Studio (через совместимый прокси) — данные не уходят.
- **Облако:** сначала локально анонимизируйте → проверьте руками → только потом дайте агенту
  читать `demo/green_anon_reviewed/`.

Агенту запрещено читать `demo/red_raw_local_only/` (см. `.claudeignore`).

## Куда смотреть

- `prompts/PROMPTS.md` — 8 основных промптов + шаг безопасности + продвинутое.
- `README_FOR_CLINICIANS.md` — как это применять в практике, без жаргона.
- `checklists/` — печатные чек-листы (согласие, анонимизация, аудит вывода).
- `sessions-ru/` — синтетические сессии (2 клиента × 5) + ключи.
- `reference-outputs/` — заранее посчитанные результаты.
- `eval/` — как мы оценивали англоязычную модель анонимизации (метрики).
- `briefing/` — материалы ревью и научные источники.

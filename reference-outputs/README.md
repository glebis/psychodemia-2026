# reference-outputs/ — предвычисленные эталонные результаты

Это **страховочная сетка для живого доклада** (Psychodemia 2026, мастер-класс «Паттерны в массиве сессий»).

> **Регенерировано после rebuild синтетических данных (2026-05-29).** Транскрипты `sessions-ru/` были переписаны более реалистично: искажения размещены по спектру ясности (clear vs borderline), посажены «приманки» (формулировки, похожие на искажения, но ими не являющиеся), терапевт делает реальные ошибки, есть кризисная и «не-событийная» сессии. Эталоны ниже пересчитаны **из новых транскриптов** и сверены с обновлёнными `ANSWER-KEY.md`.

## Что это

Каждый файл — результат одного из промптов из `prompts/PROMPTS.md`, **реально выполненный** на синтетических данных (`sessions-ru/client-a` — Марина; `sessions-ru/client-b` — Игорь). Анализ делался из самих транскриптов, затем сверялся с ground-truth в `ANSWER-KEY.md` каждого клиента (строка **«Сверка с ключом»** в конце каждого файла).

## Когда показывать

Показывайте, **если живой запуск тормозит, падает или уводит в сторону**. Принцип демо — «что заложено vs. что нашёл AI».

## Важная оговорка

**Это предвычисленные страховочные эталоны на СИНТЕТИЧЕСКИХ данных, регенерированные после rebuild на реализм.** Живой результат будет **отличаться от запуска к запуску**: LLM недетерминированы — формулировки, порядок, точный счёт искажений ±1–2 (особенно на пограничных кластерах, где разумные оценщики расходятся). Это нормально и честно — об этом стоит сказать аудитории. Устойчиво воспроизводятся **качественные выводы** (тренды, разрывы альянса, зоны избегания, разрывы в ДЗ, доминирующее/замещающее искажение) — они и есть суть демонстрации, а не точные цифры.

**ACT и психодинамика — ОТДЕЛЬНО:** это **exploratory** линзы, гипотезы-для-супервизии, не диагнозы и не измерения. Психодинамический вывод по тексту без невербалики особенно интерпретативен — там **уверенность НИЗКАЯ по умолчанию**, защиты даны только на уровне грубого различения. Не подавать как «вот паттерн клиента», только как материал для размышления клинициста.

## Этическая рамка (произнести вслух)

AI здесь — **микроскоп, а не хирург**. Эти выходы — гипотезы для рефлексии и супервизии, **не диагнозы**. Никакой оценки суицидального риска, кризисных интервенций или автоматических решений о лечении. Оценка риска — всегда только человек. Данные полностью синтетические, реальных людей нет.
